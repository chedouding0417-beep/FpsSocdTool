# FPS SOCD 急停助手

一个 Windows 小工具：开启后，**松开 A 自动轻点 D、松开 D 自动轻点 A；松开 W 自动轻点 S、松开 S 自动轻点 W**，利用游戏中的反向输入来缩短急停/变向的时间。横向和纵向两轴互相独立。

程序常驻系统托盘，默认用 `Ctrl+Shift+O` 开启或暂停，`F9` 紧急停止。不需要安装驱动，不联网，不读写游戏内存。

> ⚠️ **使用风险提示**
>
> 这是一个模拟键盘输入（宏）的工具。在线竞技游戏的反作弊系统可能拦截、检测或判定此类输入违规，导致警告、封号等处罚。请先确认游戏规则是否允许；**不要在禁止宏/第三方输入增强的在线对局中使用**。建议仅用于单机、训练场或允许宏的模式，风险自负。

## 下载

从 [Releases](https://github.com/chedouding0417-beep/FpsSocdTool/releases) 下载最新的 `FpsSocdTool.exe`，放到任意目录直接运行即可（程序清单要求管理员权限，首次运行会弹 UAC）。也可以按下面的「实现说明」自行编译，不用信任任何预编译二进制。

## 快速开始

1. 程序已经设置为**登录时自动启动**（计划任务 `FpsSocdToolAutoStart`，管理员权限，无需每次点 UAC，登录后约 30 秒启动）。也可以从开始菜单 `FpsSocdTool` → “FPS SOCD 急停助手”手动启动；手动启动会弹 UAC。
2. 托盘会出现新的黑底红边双箭头图标。**灰色 = 已暂停，亮色 = 已开启**。
3. 自启动**不会自动开启，也不会弹菜单**；按 `Ctrl+Shift+O` 开启/暂停，然后松开 A/D/W/S 试试效果；按 `F9` 可随时紧急停止。
4. 右键托盘图标，可以：
   - 调整反向点按时长；
   - 打开/重新加载配置文件；
   - 查看日志；
   - 退出程序。
5. 程序文件位于 `C:\FpsSocdTool`；首次运行会在用户数据目录 `%LOCALAPPDATA%\FpsSocdTool` 生成 `config.ini` 和 `socd.log`（配置和日志不放在 C 盘根目录的程序文件夹里，避免写入权限问题）。登录自启任务为 `FpsSocdToolAutoStart`，可在任务计划程序中查看/禁用。

> **看不到托盘图标？** Windows 11 默认会把新程序的图标收进任务栏的隐藏图标区。可以点击任务栏上的 `^` / `>` 箭头（在时钟附近）展开后找到新的双箭头图标；设置 > 个性化 > 任务栏 > 其他系统托盘图标里也可以把它设为显示。
>
> 如果找不到图标，从开始菜单 `FpsSocdTool` → **“FPS SOCD 控制菜单”** 启动：程序没启动时会启动并弹出菜单，已经启动时会直接弹出菜单。桌面快捷方式已经移除，避免占位置。这个入口不依赖托盘图标。

> 开启状态下，工具会监听**所有程序**的 A/D 按键。在游戏里打字聊天、在浏览器输入 A/D 时，也可能被补成相反方向的字母。**打字或切出游戏前，请先按 `Ctrl+Shift+O` 暂停**；也可以用配置里的 `OnlyInProcess` 限制为仅在游戏是前台窗口时生效（同一进程内的游戏聊天仍无法区分，打字前依然建议暂停）。

## 默认参数

| 项目 | 默认值 | 说明 |
|---|---|---|
| 开启/暂停热键 | `Ctrl+Shift+O` | 全局生效；Raw Input 与系统热键双通道 |
| 紧急停止热键 | `F9` | 强制暂停，并松开正在补按的键 |
| 反向点按时长 | `35 ms` | 松开 A/D/W/S 后，对向键按下多久（支持 1-300） |
| 最小间隔 | `70 ms` | 两次补键之间的冷却，避免连点抖动 |
| 识别/发送按键 | `A` / `D` + `W` / `S` | 横向和纵向两轴独立；`UseScanCodes` 同时控制识别和发送模式 |
| 启动即开启 | `false` | 默认启动后为暂停状态 |

反向点按时长支持 **1-300 ms**：控制菜单里有 1/2/3/4/5/10…300 的预设，也有“自定义（1-300 ms）”输入框；也可以直接编辑 `config.ini`。工具运行期间会把 Windows 定时器精度提高到 1 ms，1-5 ms 的短补键更接近设定值。托盘预设只修改 `TapMs` 这一行，不会覆盖其他手动修改。

## 调参建议

- **感觉反向没有效果**：把补键时长从 35 ms 逐步调到 45～60 ms；或在游戏里确认 A/D 或 W/S 同时按下时游戏会减速（有些游戏使用“最后按键优先”，这种逻辑下效果会不同）。
- **反向冲过头 / 有抖动感**：把补键时长降到 1～5 ms（菜单已支持），或增大 `CooldownMs`。
- **游戏完全没反应**：先确认程序是**以管理员身份运行**（UAC 选是）；Raw Input 监听在部分环境/反作弊下需要提权。然后尝试把 `UseScanCodes` 改为 `false`。该选项会同时切换“识别物理按键”和“发送按键”的方式：`true` 全部用扫描码，`false` 全部用虚拟键；两种模式不能混用，否则可能出现键位错乱。如果游戏以管理员权限运行，本工具也要以管理员身份运行，否则可能无法把按键送到游戏。
- **补键方向键被游戏改绑**：本工具固定使用 A/D，不支持改绑其他键。若游戏把移动键改成其他键，需要修改源码中的 `SocdKey` 定义并重新编译。
- **想限制到游戏内**：在 `config.ini` 的 `OnlyInProcess` 填入游戏进程名，例如 `OnlyInProcess=game.exe`。部分带内核反作弊的游戏会保护进程，导致无法读取进程名；此时工具会记录一条警告并放行（过滤器对这类进程失效），最稳妥的做法仍是保持留空、手动按 Ctrl+Shift+O 暂停（但也会影响游戏外的输入）。
- **补键时长修改后**：托盘菜单里的预设会立即生效，并且只会修改配置文件里的 `TapMs` 行；手动编辑 `config.ini` 的其他内容后，右键托盘 →“重新加载配置”。发送模式会立即生效；**热键修改需要重启工具**（重新加载时会继续使用旧热键，避免新热键注册失败后失去控制）。

## 配置文件

文件位置：优先使用 `%LOCALAPPDATA%\FpsSocdTool\config.ini`（UTF-8 编码），通常完整路径是 `C:\Users\<用户名>\AppData\Local\FpsSocdTool\config.ini`。如果该位置不可写，会回退到程序目录 `C:\FpsSocdTool\config.ini`。托盘菜单里的“打开配置文件”会直接打开当前使用的文件。

```ini
[General]
StartEnabled=false      ; 启动工具后是否立即开启
TapMs=35                ; 反向点按持续时间，1-300 ms
CooldownMs=70           ; 两次补键的最小间隔，0-2000 ms
SkipIfOppositeHeld=true ; 对向键正被按住时跳过补键
UseScanCodes=true       ; true=识别和发送都用扫描码，false=都用虚拟键
OnlyInProcess=          ; 仅在这些进程为前台时生效，逗号分隔；留空=所有程序
Beep=true               ; 切换开关时提示音
Notify=true             ; 切换开关时托盘气泡
LogTaps=false           ; 是否记录每次补键（调试用）

[Hotkeys]
Toggle=Ctrl+Shift+O
FallbackToggle=
Panic=F9
```

热键支持：`F1`～`F24`、单个字母/数字、`Space`、`Tab`、`Enter`、`Esc`、方向键等，可加 `Ctrl` / `Alt` / `Shift` / `Win` 修饰，例如 `Ctrl+Alt+S`。不能把单独的 A 或 D 设为热键，否则会吞掉移动键。

修改配置后，右键托盘 →“重新加载配置”即可生效。拼写错误的配置项会在重新加载/启动时提示，并写入 `socd.log`；热键冲突或配置文件损坏时，程序会使用默认值并记录原因。热键本身修改后需要重启程序才会重新注册。

## 常见问题

**Q：看不到托盘图标？**  
A：程序已经在运行，只是 Windows 11/FluentFlyout 把新图标放进了隐藏图标区。点击任务栏时钟附近的 `^` / `>` 展开；或者从开始菜单 `FpsSocdTool` → “FPS SOCD 控制菜单”让正在运行的实例弹出控制菜单。全屏游戏里任务栏和托盘图标本来就看不到，先按 `Alt+Tab` 或 `Win` 回到桌面再找。

**Q：按 Ctrl+Shift+O 没反应？**  
A：从开始菜单 `FpsSocdTool` → “FPS SOCD 控制菜单”，从菜单直接开启/暂停，用来确认工具本身是否工作。热键同时走系统热键和 Raw Input 两条路径；如果系统里已有其他程序占用这个组合，工具日志会记录，并可在 `config.ini` 里换一个组合后重启。以管理员权限运行游戏时，本工具也建议以管理员权限运行。

**Q：游戏里按 Ctrl+Shift+O 切换了，但松开 A/D 没有任何反应？**  
A：可能原因：游戏反作弊拦截了模拟输入；游戏按住了对向键导致跳过（`SkipIfOppositeHeld`）；`OnlyInProcess` 配置不匹配；或游戏不读取 Windows 合成按键。可尝试 `UseScanCodes=false`、管理员运行，或换一个没有反作弊限制的环境测试。**本工具不会、也不应该绕过反作弊。**

**Q：为什么松开 A 后角色会往右轻微漂移？**  
A：这是反向点按本身造成的。把 `TapMs` 调低（例如 20 ms）通常可以减轻；不同游戏、不同帧率下最佳值不同。

**Q：按键会不会卡住？**  
A：每次补键都会用定时器自动松开；如果这一次 `SendInput` 失败（例如桌面切换、权限提升的窗口抢焦点），程序会保留“待松开”状态并自动重试，按 `F9` 暂停或退出时也会再尝试一次。但如果程序被强制结束、系统卡死、游戏持续拦截输入，仍可能出现异常。遇到按键卡住时，先按 `F9`；仍不可用就退出游戏/重开工具。不要在补键进行中直接强杀进程。

**Q：开启后聊天打字会乱？**  
A：这是全局按键监听的副作用。打字前按 `Ctrl+Shift+O` 暂停，打完再开启。

**Q：怎么卸载？**  
A：右键托盘 →“退出”，或从开始菜单 `FpsSocdTool` → “FPS SOCD 控制菜单”打开菜单后选择“退出”，然后删除整个 `FpsSocdTool` 文件夹即可。程序本身不写注册表、不安装服务；登录自启是独立的计划任务 `FpsSocdToolAutoStart`，如果不再需要，可在任务计划程序里删除。

**Q：为什么 Windows/杀毒软件可能提示风险？**  
A：程序是自行编译的、未签名的输入模拟工具，可能被 SmartScreen 或杀毒软件误判；它不联网，也不读取游戏内存。你可以用附带的源码和 `Build.bat` 自行重新编译，确认没有额外行为。

## 实现说明

- 使用 Win32 **Raw Input**（`RegisterRawInputDevices` + `RIDEV_INPUTSINK`）监听物理 A/D/W/S，即使游戏在前台也能收到；横向 A/D 和纵向 W/S 是两个独立状态机。热键同时通过系统热键和 Raw Input 两条路径处理。程序清单要求管理员权限，启动时会弹 UAC。
- 通过 `SendInput` 发送反向按键。Raw Input 也会回显本工具注入的按键，因此程序用 30 ms 的合成输入抑制窗口把它过滤掉，避免补出的 D 被当成实体 D 而取消自动松开。
- Raw Input 只负责读取；补键仍由 `SendInput` 注入，是否被游戏接受仍取决于游戏本身的输入/反作弊策略。
- 识别物理键和发送按键使用同一种键身份（扫描码模式或虚拟键模式），避免布局不一致时误判或按错键。
- 松开 A/W 后立刻按下 D/S，并用定时器在 `TapMs` 毫秒后松开；反向同理。运行期间通过 `timeBeginPeriod(1)` 把定时器精度提高到 1 ms，支持很短的补键。
- 对向键正被按住时跳过补键，避免重复按下。
- 若补键期间用户又按下了同一个实体键，会取消自动松开，交给实体键的松开事件处理，避免“按键还在按但游戏收到 key-up”的异常。
- 若 key-down 失败，本次补键直接取消，不会发送孤儿 key-up；若 key-up 失败，会保留待释放状态并定时重试，暂停/退出时也会尝试释放。
- 只监听、只注入 A/D 的按下/松开，不读取其他按键内容，不联网，不注入游戏进程。

源码位于 `src/`，使用 Windows 自带的 .NET Framework 4.x 编译器构建，无 NuGet 依赖：

```powershell
# 编译并运行自测
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -SelfTest
```

或双击 `Build.bat` 重新编译。自测不会发送真实按键。

调试模式（只在 `socd.log` 记录将要发送的按键，不实际注入）：

```powershell
.\FpsSocdTool.exe --dry-run
```

## 兼容性

- Windows 10 / Windows 11（需要系统自带的 .NET Framework 4.x，通常无需额外安装）。
- 程序目录：`C:\FpsSocdTool`；配置和日志：`%LOCALAPPDATA%\FpsSocdTool`。
- 不适用于主机、macOS、Linux。
- 固定使用 A/D 键。非标准键盘布局（AZERTY、Dvorak 等）可能因扫描码/虚拟键映射不同而按键不符；通常把 `UseScanCodes` 切换为 `false` 或改用标准布局键盘。
- 不保证在所有游戏/反作弊环境工作；无法绕过输入保护或反作弊。
- 游戏必须允许同时按下相反方向键并据此减速；如果游戏采用“最后输入优先”或直接清空方向，效果可能不符合预期。
